# IBM Certificate – SQL and Relational Databases

This folder contains my IBM certificate for the **SQL and Relational Databases** course.

## Overview

This course introduced the fundamentals of relational databases and SQL. It helped me understand how data is structured, stored, queried, and managed in database systems.

Through this certificate, I strengthened my understanding of database concepts and learned how SQL is used to interact with relational databases in a practical way.

## What I learned

During this course, I learned about:

- databases and relational database concepts
- tables, rows, columns, keys, and relationships
- primary keys and foreign keys
- entity-relationship concepts
- SQL syntax and structure
- `CREATE`, `INSERT`, `SELECT`, `UPDATE`, and `DELETE`
- filtering data with `WHERE`
- sorting results with `ORDER BY`
- removing duplicates with `DISTINCT`
- pattern matching with `LIKE`
- grouping data with `GROUP BY`
- filtering grouped results with `HAVING`
- joining tables with `INNER JOIN` and `OUTER JOIN`

## Skills developed

This course helped me develop the following skills:

- understanding relational database structure
- writing basic and intermediate SQL queries
- retrieving and filtering data
- updating and managing table records
- working with database constraints
- understanding how tables are connected through keys
- using joins to combine data from multiple tables

## Why this matters

SQL is an essential skill for working with data, backend systems, analytics, and software applications. This course gave me a stronger foundation in data management and helped me better understand how applications store and use structured information.

It also supports my broader learning in software development, backend systems, and AI-related projects where structured data and database organization are important.


# Project Management Fundamentals

This directory contains my IBM certificate for the **Project Management Fundamentals** course completed during **Trimester 2**.

## Certificate Information

- **Course name:** Project Management Fundamentals
- **Platform:** IBM SkillsBuild
- **Repository:** `holbertonschool-france-certificates-ibm`
- **Directory:** `certificates-trimester-2`
- **Certificate file:** `certificate-project-management-1`

## Course Summary

This course introduced the fundamentals of project management and helped me understand how projects are organized, planned, executed, monitored, and closed.

It provided a clear view of the role of a project manager, the main phases of the project lifecycle, and the importance of communication, planning, quality, risk management, and stakeholder coordination in delivering a successful project.

## Key Concepts Learned

- definition and characteristics of a project
- role and responsibilities of a project manager
- project stakeholders and their interests
- project lifecycle phases
- project scope, goals, and success criteria
- project charter and project planning
- work breakdown structure (WBS)
- effort, duration, and scheduling
- budgeting and resource planning
- quality planning and quality control
- risk identification, analysis, and response planning
- communication management
- change management
- project closure and lessons learned
- project management frameworks such as Agile, Waterfall, and Hybrid

## Practical Skills Gained

Through this certificate, I improved my ability to:

- understand how a project is structured from start to finish
- identify stakeholder roles and expectations
- define project scope and objectives clearly
- break work into manageable tasks
- estimate effort, duration, and cost
- organize tasks into a schedule with dependencies
- recognize project risks and plan appropriate responses
- support project communication and coordination
- understand how different project management frameworks are applied
- appreciate the importance of documentation, closure, and continuous improvement

## Personal Takeaway

This certificate helped me better understand how projects are managed in professional environments. It gave me a stronger foundation in planning, coordination, communication, and structured execution.

It is especially useful for collaborative technical projects, where success depends not only on technical skills, but also on organization, teamwork, decision-making, and the ability to manage scope, time, cost, quality, and risks effectively.
